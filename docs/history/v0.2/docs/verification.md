## Failures retained and compatibility fixes

Early live attempts exposed an empty proxy model value, model tool loops/pseudo-tool markup, and native adapter schema exposure. These attempts remain failures in their saved records. The fixes use explicit model defaults, a stop-after-empty-search instruction, validation of public answers and a provider-facing course-tool allowlist. Returned Deep Agents tool calls are also checked against the effective exposed names before reaching the runtime; blocked calls retain measured provider usage. Fabric's native execution allowlist remains in force; its original Relay events are not rewritten. Ledgers show both received and exposed tool names.

The first managed OpenShell request timed out; its image had omitted an explicit reasoning setting. The reviewed Deep Agents image now declares `reasoning_effort: none`, matching the working local harness. A later request reached the MCP tool but supplied `days: "Saturday"` to a list-only schema. The shared tool now accepts and explicitly normalizes weekday names while rejecting invalid values; trusted application constraints still take precedence. Both failed trials and their native Intake traces are preserved.

Other checks caught and fixed delayed-body admission after lease closure, undeployment before session cleanup, invalid Platform targets silently choosing local, and UI controls changing an in-flight conversation. None of these fixes converts earlier failed outputs into successes.

Final regression checks also force lifecycle evidence-write failures and verify restoration of interpreter, retry, gateway and tool-allowlist state. Remote native recovery requires its explicitly selected executor configuration; it cannot inherit the host's local gateway selection.

## Practical limits

- **Singapore NGC Extended is unavailable on this host.** Its access/materialization and OCEAN conditioning remain unverified. The UI reports that boundary before inference and does not fall back to HF.
- Existing **remote Helix**, Brev and frontier-provider profiles are implemented but have not been exercised here. Local Platform hosting and hosted NIM inference were exercised independently.
- **Managed Hermes Relay correlation is limited by Fabric 0.6.1.** Native export exists, but the public response does not provide a reliable bridge to its separate Relay session identity. The UI reports the limitation; it does not substitute another session's trace.
- The local Helix checks cover narrow, inspectable assertions. Missing evidence and inapplicable criteria remain distinct; the aggregate does not certify every claim. Official course snapshots can become stale and do not prove current seats, fees or personal funding eligibility.
- Data Designer's native one-row profiling warning remains visible. Generated salary, preferences and profiles are hypotheses, not observed resident behaviour or entitlement.
- Model and tool completion are stochastic. Failed answers, unknown usage, incomplete conditions and native warnings remain evidence. Small diagnostic experiments do not estimate population demand or human outcomes.
