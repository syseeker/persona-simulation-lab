## Singapore Personas

This lab supports the public [NVIDIA Nemotron Personas Singapore dataset](https://huggingface.co/datasets/nvidia/Nemotron-Personas-Singapore), provided by NVIDIA under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The application pins revision `a3994709410410f834bd949d643d3f2796908969`. Dataset files and extracted records are downloaded locally and excluded from this repository.

The application parses list-valued fields, selects a small review panel and constructs simulation inputs. Optional Data Designer output adds separately labelled hypothetical learning preferences. These changes do not alter the original profile JSON, and generated preferences are not source attributes. This application is an independent learning project and does not imply endorsement by NVIDIA.

NGC Extended is a separate distribution governed by its own access requirements and NVIDIA dataset terms. The repository contains no NGC dataset records. Review the current terms before obtaining or using that distribution.

## Course Sources

The catalogue contains a small dated factual snapshot with links and capture dates for official NUS, ITE/AIC and People's Association onePA listings. Provider names identify the source; course availability, fees and terms remain with the provider. Descriptions are short paraphrases for this learning application. No course materials are included.
